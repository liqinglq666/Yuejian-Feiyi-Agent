# 功能逻辑 V3：五种业务场景

本轮仅重构 Python Agent 内部逻辑。网页布局、API 路由、五个入口、SSE 事件、平台限额和导出协议保持兼容；不引入额外的模型调用。

## 场景处理方式

- **游客路线**：城市与时长优先；建议性行程节点、顺序和需要核实的现场信息，缺少坐标时不虚构交通分钟数
- **学生研学**：可观察的学习目标、现场任务卡、采访许可、记录表及学习成果；未指定学段时同时提供基础/进阶方案
- **亲子体验**：独立于游客路线的儿童互动策略；不猜儿童年龄，减少节点，增加成人陪同、休息、工具和人群风险提醒
- **内容创作**：图文文案与短视频使用不同策略；区分文化事实与创意表达，短视频要求镜头、旁白、时长对应并检查素材授权
- **非遗问答**：先回答用户真实问题，优先查直接匹配项目名录，知识不足时坦诚说明

新增 `services/scenarios.py` 统一封装场景策略、缺失信息的保守处理和启发式诊断；`services/planner.py` 按场景生成确定性步骤；`services/prompt_builder.py` 分别在初次生成和修改时纳入业务要求。前端继续沿用现有结果标题，不破坏现有分段和导出。图文/视频是「内容创作」内两个模式，不是新增第六个首页入口。

## 安全与兼容性

- 当 scene 与 task_type 不一致时，HTTP 400 阻止进入付费模型调用；内容创作允许 social 或 video
- 城市、学段、儿童年龄、内容发布平台未提供时以保守建议处理，不猜测、不错误拒绝
- API 返回的 `quality.scene_review_hints` 仅是关键词启发式提醒，不是对儿童安全、路线合理性或生成事实的人工/机器证明
- 官方来源是否直接相关仍按已有 RAG 核验逻辑判断；场景规划不会把无关官方条目计作当前主题证据
- `backend/` 是 Vercel 多服务部署所需镜像，本轮同步全部后端文件，并增加一致性自动测试
- 不调用实时地图、开放时间或付费大模型；实际可访问性仍需到官方平台核实
