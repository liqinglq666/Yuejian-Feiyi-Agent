# 粤见非遗 · 视觉与交互规范

## 使用流程
用户在首页选择体验类型，输入需求，点击“生成我的方案”，进入工作台继续生成、调整和导出。
首页不重复设置项，不展示尚未实现的景点预订、地图和活动信息。工作台保留既有模型设置、兴趣偏好、历史记录、资料来源及三类导出。

## 视觉基调
岭南民俗插画可以明亮、有手工纸张质感，但操作界面要安静。图片是文化主角，按钮和表单不与插画争抢颜色。避免大面积渐变、高饱和按钮组合、重复说明标题及层层卡片。

- 页底：#FAF9F6；功能表面：#FFFFFF
- 正文：#28312E；辅助文字：#67716C
- 操作主色：#2D4940；悬停：#1E352D
- 文化红：#AC4556，限定品牌标识、类型选中态及局部强调
- 边界：#E1E6E2；浅蓝：#DCECF0，谨慎用于细节
- 圆角约 7–12px，避免各种组件都使用同一巨型圆角
- 中文标题使用宋体系列，操作与正文使用清晰的无衬线
- 统一 4/8/12/16/24/32px 间距节奏；按钮保证足够可点击面积

## 版式
桌面：首页左侧为直接可操作的表单，右侧为清晰的非遗插画。三条文化示例以简洁的横向入口呈现。移动端先看标题与输入，插画退后；不让大片纯装饰内容阻挡用户完成任务。

工作台以生成及结果为主，左栏仅承载体验类型与最近方案。高级设置默认折叠，不使用与用户任务无关的英文编号和标签。

## 功能回归
保持原来的 TaskRequest、五种场景、SSE generate/revise、平台 API 与 BYOK、Redis 配额、三种导出和 sessionStorage 草稿传递。生成、失败、取消、修改、复制和保存均有反馈。

验证 375 / 768 / 1440px 视口的首页输入至工作台流转、图像清晰度、无横向溢出、键盘焦点与操作反馈。真实模型调用另行按付费额度控制。
