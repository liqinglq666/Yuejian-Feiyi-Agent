# 粤见非遗 · 视觉规范

**原则**：文化氛围鲜明，操作界面克制。让访客直接完成「选类型 → 描述需求 → 生成方案」，不用冗余卡片和介绍堆砌页面。

## 品牌色

| 用途 | 色值 | 规则 |
|---|---|---|
| 玫红 | #E72451 | 品牌印章、选中场景、标题局部强调 |
| 深玫红 | #CE1240 | 主要提交按钮配白字，满足文本对比度 |
| 淡黄 | #FEF97B | 工作台头图、重点标题背景，仅配深色文字 |
| 天蓝 | #78C3FE | 按钮阴影、背景局部色块 |
| 纸白 | #FFFAF0 | 首屏与内容底色 |
| 墨黑 | #252127 | 标题与正文 |
| 辅助灰 | #695E60 | 次要说明 |

品牌色用于标识与少量强调，不能让正文难读；长段文字不用玫红，浅黄/天蓝不配白色正文。状态同时用文案表达。

## 素材与响应式

素材统一存放于 web/public/heritage/。首页桌面使用 hero-desktop.webp，手机使用 hero-mobile.webp。头图左侧留白用于真实 HTML 文字，不将按钮或标题写进图片。灵感示例图按需懒加载并有替代文本；点击后直接带入工作台的真实输入。

桌面布局：主题 Hero → 5 个紧凑类型选择 → 核心输入/生成 → 3 个灵感示例。手机布局：图片与标题比例重排，类型按钮折行，表单操作保持连贯。工作台沿用原有 SSE/API/模型设置和结果结构。

## 验收要求

- 输入为空会提示原因，焦点自动回到输入区
- 首页灵感卡片可填充类型、城市和文本
- 首页内容会传至工作台，不需要重新填写
- 五类场景、生成、取消、修改、来源、Word/MD/TXT 导出不变
- 375px、768px、1440px 视口无页面级横向溢出
- 原生按钮、焦点、弹窗 Escape、错误与加载反馈保留
- Redis 限额和 BYOK 安全边界不改变

图片和主题先在预览分支验收，之后再决定是否合并生产站。
