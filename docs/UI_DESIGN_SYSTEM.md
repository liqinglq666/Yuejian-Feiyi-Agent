# UI 规范｜粤见非遗
本规范覆盖 Next.js 首页、工作台、弹窗、生成结果与手机端；保留现有业务 API 和模型设置。

## 体验原则
- 第一次使用：选体验类型 → 描述需求 → 生成 → 调整或导出。首页和工作台的任务类型保持一致。
- 只让必要输入默认可见。城市、时长、身份、风格放进「更多选项」；个人 API 设置独立于主流程。
- 操作要有结果：禁用原因、等待、生成中、取消、错误、复制、文件下载有可理解的状态文字。
- 无实际业务含义的品牌段落、编号、装饰标签和重复操作入口不应出现。

## 色彩
- 页面 Canvas #F6F8F6；表面 Surface #FFFFFF；辅助底色 #F0F4F0
- 标题 Ink #20382F；主要按钮 Forest #20503E，悬停 #153B2E
- 正文辅助 #66796C；边界线 #DBE3DC；文化点缀 #A04E39（非按钮主色）
- 错误 #A23C32、错误背景 #FFF0ED；成功 #286D4E

## 文字、尺寸与间距
- 中文正文：系统无衬线 16px，行高约 1.6；模块文字 14px；辅助 12–13px；首页标题 30–46px
- 品牌与首页标题用系统宋体系列；表单、正文、功能界面用系统无衬线
- 间距基数 4px：8/12/16/20/24/32/40px；圆角 8 或 12px
- 内容宽度 1180px；首页核心任务表单 1080px；桌面左侧场景栏 225px
- 点按目标优先最少 44×44；只有短小标签允许更小但不低于 38px

## 交互与无障碍
- 每项操作使用原生 button、链接使用 Link；表单文字有 label；键盘 Tab、Enter、Escape 可操作。
- 所有焦点具有显式边框；弹窗打开聚焦关闭按钮、Tab 保持在弹窗内、Escape 关闭、返回原焦点。
- 错误与成功提示分别使用 role=alert / aria-live；加载状态 role=status；支持减少动态效果。
- 手机断点 760px、540px；保留缩放，表格在内容容器内横向滚动，弹窗考虑安全区域。
- 方案内容与用户输入自动换行；长段内容不因固定高度被截断。

## 发布回归清单
- 首页五类任务、示例、表单校验、城市选择、首页 → 工作台草稿衔接
- 工作台五类任务、主题/更多选项、BYOK 与平台模式、Ctrl/⌘+Enter、生成/取消/修改
- Markdown 分段/检索来源、复制、Word/Markdown/TXT 导出、最近记录
- 375 / 768 / 1440px 无页面级横向溢出；弹窗与抽屉可关闭；全程键盘可达
- 生产的 Redis 限额及后端 API 保持现有实现，不随视觉重构变化
