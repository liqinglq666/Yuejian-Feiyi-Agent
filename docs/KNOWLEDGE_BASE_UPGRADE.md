# 结构化非遗知识库

首批 8 条官方来源项目记录保存于 data/heritage_records.json，镜像位于 backend/data/heritage_records.json。内容包括项目名称、别名、城市、类别、国家级名录编号、来源名称、官方项目页链接、核验日期、目标人群、体验建议和实时核验提示。

核验日期代表项目核对来源网页的时间，而非官方活动或项目发布日期。体验建议是本产品的策划建议，并非官方已开放的活动。旧 Markdown 文档用于创意规划与内部参考，不能被自动标记为官方资料。

检索模块仅在文本相关性足够时检索；来源权重优先官方记录。没有可追溯来源时，Agent 必须保守说明，不编造票价、演出和营业信息。

运行 `python -m scripts.run_benchmark` 检查 40 条跨五种场景的任务路由、检索关键词与官方来源覆盖。该评测不等于答案事实准确率；后续仍需人工核验事实主张。

增加条目时必须核验具体的官方项目页面、填写真实链接与核验日期，并同步 canonical 和 backend 镜像。
