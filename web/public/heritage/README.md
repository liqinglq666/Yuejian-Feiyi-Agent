# 粤见非遗 · 插画素材

专为网站制作的原创民俗风格插画，统一为经过压缩的 WebP。页面文案与按钮使用真实 HTML，不写进插画。

| 文件名 | 使用场景 |
|---|---|
| `hero-desktop.webp` | 首页桌面横幅背景，左侧留白放文字 |
| `hero-mobile.webp` | 首页手机端竖屏画幅 |
| `inspiration-festival.webp` | 灵感示例：民俗巡游、城市漫游 |
| `inspiration-dragon-boat.webp` | 灵感示例：节庆、龙舟文化 |
| `inspiration-theatre.webp` | 灵感示例：戏曲、文化研学 |
| `studio-empty.webp` | 工作台引导与等待生成 |
| `ornament-corner.webp` | 少量页面局部花檐装饰，透明背景 |
| `ornament-divider.webp` | 可选页脚/章节分隔装饰，透明背景 |

主色 `#E72451`，辅助浅黄 `#FEF97B`，天蓝 `#78C3FE`；UI文字和底色应保持足够对比。素材不承担必需交互信息；浏览器应按设备加载对应 Hero，其他图懒加载。
